The 3 Diseases of Self-Hosting (From the Essay)

Disease #1: Windows/macOS on main machine. Users offload tasks to remote VPS instances simply because their local OS cannot natively run clean Unix tools. Cure: Run Linux (e.g. Gentoo) locally instead.

Disease #2: Muh Devices. Bloated services deployed just to push files to locked-down phones. Cure: Lightweight HFS, FTP, or direct local WebDAV.

Disease #3: Muh FREEDOM (Time-Sink Trap). Noble quest for autonomy ruined by fragile 40-step configurations that waste days. If it cannot boot with one command on a tiny Linux VPS, it is not viable.

The Golden Rule for Maintainers

“If it can’t be installed and working after partitioning a low-resource fresh linux VPS and running a single command, it is not ready for this use case.”

Your software must install instantly, require no manual configuration file tinkering to start working, and must run on a $3-5/month low-resource VPS without crashing or thrashing swap.
